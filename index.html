A pays B: only A’s and B’s chains get a new block

Each wallet keeps its own chain of transactions. A payment only updates the sender’s and receiver’s chains, so it never waits for anyone else and completes in milliseconds.

Mirrored everywhere

Many copies, no single point of failure

Every wallet chain is mirrored to many different chain holders. Each holder keeps a full copy, so the record stays available and consistent even if some holders go offline.
